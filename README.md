# School Projects

A collection of C++ projects built for coursework at John Jay College of Criminal Justice (CUNY), CS & Information Security.

## Projects

| Project | Description |
|---|---|
| [`penalty-shootout-game/`](./penalty-shootout-game) | Console-based penalty shootout simulator (solo project) |
| [`quickcart/`](./quickcart) | Console-based grocery shopping simulator, OOP capstone project (solo project) |
| [`bank-account-system/`](./bank-account-system) | Console-based banking system
| [`gpa-calculator/`](./gpa-calculator) | Console-based student transcript reporter / GPA calculator (solo project) |

Each subfolder has its own README with build/run instructions and a description of the project's design.
